# 加密貨幣量化研究平台

[English](README.md) · [繁體中文](README.zh-TW.md)

這是一個用 Python 開發的加密貨幣量化研究平台，重點放在研究流程、資料正確性與可重現性。

目標不是累積漂亮的回測結果，而是讓弱假說能被可靠淘汰，同時避免污染後續證據。

## 目前包含

- Binance 現貨與 USD-M 市場資料管線
- 嚴格限制未來資料存取的研究資料視圖
- 從市場事件、執行成本到策略生命週期的分階段研究流程
- 與 Git 狀態綁定的設定、研究產物與決策紀錄
- 測試網下單與未知委託狀態處理
- 型別檢查、程式碼檢查與自動化測試

研究審查與自動研究流程仍在持續完善。保護性留出資料與敏感研究決策維持獨立治理。
